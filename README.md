# 데드 마치 (Dead March)

생존자 무리를 좌우로 이끌어 숫자 게이트로 인원을 불리고, 같은 병과끼리 합체해 좀비 떼를 뚫는 모바일 러너 전투 게임입니다.

- 휴대폰으로 해보기: https://joongyub.github.io/dead-march/
- 성능 수치 보기: https://joongyub.github.io/dead-march/?debug=1
- 병력 5,000 스트레스 테스트: https://joongyub.github.io/dead-march/?debug=1&stress=1
- 홈 화면에 추가하면 앱처럼 전체 화면으로 실행됩니다.

스테이지별 난이도 표는 [docs/balance.md](docs/balance.md)에 있습니다.

개발 규칙과 성능 예산은 [CLAUDE.md](CLAUDE.md)에 있습니다.
