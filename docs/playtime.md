# 플레이 시간 추정

`npm run playtime`으로 다시 만들 수 있습니다. 전투 결과는 모두 실제 전투 시뮬레이터(src/sim/)로 그때까지 산 피난처 강화를 반영해 돌린 값입니다.

- 가상 플레이어 24명: 게이트마다 30% 확률로 나쁜 쪽을 고르고, 한 번에 15분씩 하고 4시간 쉬는(하루 4번) 사람.
- 전투마다 앞뒤 화면에 25초를 더함. 다음 스테이지 승률이 20% 미만이면 마지막으로 깬 스테이지를 다시 해서 자원을 모음.
- 자원은 생기는 대로 방벽·무기고를 먼저 올리고, 농장·무전실·정비고는 그보다 1~3레벨 낮게 따라감.
- 표의 값은 모두 중앙값.

**20스테이지까지 실제 플레이 1.9시간 (전투 117판, 접속 8번, 하루 4번 접속하면 약 2일).** 끝까지 간 가상 플레이어 24/24명.
